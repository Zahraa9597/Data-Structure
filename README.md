🏦 Banking System Project:

This project implements a Bank Management System using fundamental data structures in Python.

It was developed as part of a Data Structures course to demonstrate how Binary Search Trees (BSTs) and Queues can be applied in a real-world-like application.

The system allows you to manage bank accounts, process deposits, withdrawals, and transfers, and search or delete accounts — all while using data structures effectively.

🎯 Objectives

Apply core data structures (BST, Queues) to simulate a real-world banking workflow.

Reinforce understanding of tree traversal, recursion, and queue operations.

Learn how to design a menu-driven console application in Python.

⚙️ Features

✅ Create and store bank accounts using a Binary Search Tree (BST)

✅ Deposit, withdraw, and transfer funds via Queue-based transaction processing

✅ Delete accounts while maintaining BST structure

✅ Search for accounts by account number or balance range

✅ Display account details and current balances
